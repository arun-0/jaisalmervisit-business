# Guide and search foundation — editorial/technical reference

The original November 14 brief requested crawlable destination pages instead of relying only on homepage hash routes. The delivered website now has 35 editable Markdown guides, full HTML, unique metadata/canonicals, ordinary links, structured data and a generated 37-URL sitemap. Partner repetition/demo output and image descriptions were addressed. [Build/edit/check instructions](../../site/README.md) · [Release evidence](../WORKLOG.md).

Remaining content work is selected by value and evidence, not the original 40–60-page target. Useful guide information includes what to see, access, local timing/prices where verified, transport, facilities, booking inclusions, nearby options and appropriate photos/descriptions. Verify claims locally and label uncertainty; don't invent price/availability or add text merely for ads.

Existing homepage map/planner/activity links must keep working. New/changed content should preserve accessible navigation, production canonicals and real missing-page responses. The sitemap is generated from guide source; submission, processing and actual indexing are separate states.
