# Owner inputs and private evidence

This is a reference, not another todo list. [TODO.md](../TODO.md) owns commitments/dates and whether an input is currently needed. [Revenue setup](revenue-setup.md#owner-checklist) owns the exact current owner steps. Use existing authorised sessions before requesting exports or access.

| Source | Useful evidence when the selected task needs it |
|---|---|
| AdSense | Account notices/identity status, site approval, ads.txt, regional consent/settings, actual impressions/earnings/RPM and currency. Manual unit IDs only if manual units are selected. |
| GA4 | Correct property/stream, reporting timezone, country/device mix, comparable landing/source reports and internal/test traffic handling. Record consent/attribution limits. |
| Search Console | The existing verified URL-prefix property: sitemap-processing and indexing details, then query/page performance once available. Do not create another property merely to gather a report. |
| Viator | Owner-approved legal/payee account, genuine generated links, inventory fit, attribution/commission/cancellation rules and completed-outcome/payout reports. |
| Local editor/provider | A needed fact, exact product/service location, price/inclusions/cancellation terms or permitted media. Listing contact details do not establish paid referral terms. |
| Optional acquisition | Actual channel URLs, aggregate insights and permitted media when a channel becomes selected. Named access only for the necessary role; no unnecessary account connections. |

Record account/property, date range, timezone and currency with aggregates. Use a recent complete comparable window where useful, without making perfect data a progress gate. The India-first estimate must be validated with available country data; the owner's current UK location does not establish visitor or payee country.

Keep IDs, passwords/OTPs, tokens, banking/tax details, customer messages and transcript archives outside Git/chat. The owner submits private information directly to the relevant service. Redacted exports, if needed, go in ignored `private/` or `reports/raw/`; commit aggregate findings only. An anonymous booking reference/outcome is normally enough for business reconciliation.
